Adds the LeadLoop website tag to every page: lead-form capture plus your connected Meta, Google and TikTok ad pixels.

== Description ==

This plugin prints one script tag in your site's <head>. The tag:

* sends a copy of each lead-form submission to your LeadLoop board (password and card fields are never collected);
* remembers which ad a visitor came from, so the lead is attributed correctly;
* loads the Meta Pixel, Google tag and TikTok Pixel you connected in LeadLoop — skipping any you already have, so nothing fires twice.

The plugin you download from LeadLoop already contains your site key, so there is nothing to configure.

== Installation ==

1. In WordPress go to Plugins → Add New Plugin → Upload Plugin.
2. Choose the leadloop.zip file you downloaded from LeadLoop, then click Install Now.
3. Click Activate Plugin.
4. Visit your website once, then click "Check my website" in LeadLoop.

To change the site key later: Settings → LeadLoop.
